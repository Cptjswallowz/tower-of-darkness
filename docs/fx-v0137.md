## Kernel (any skill resolve)

On resolve, in order:

1. **Fired tile flash**
2. **Stroke** You ↔ foe (unless NO STROKE)
3. **Number float** — damage and/or Brace
4. **Shake** by tier
5. **Existing log** + **same hold** as today’s beat timing

| Rule | Lock |
|------|------|
| 1x / 2x | FX **reads** combat rate — **halve durations** at **2x** (`combat-2x-v0111.md`) |
| Tap-skip | Beat tap-skip **still works** |
| Fail-safe | If FX fails / stubs → **resolve + log anyway** (never block combat) |

Enemy strokes **flip direction** (foe → You).

---

## Tiers

| Tier | Stroke | Shake | Who |
|------|--------|-------|-----|
| **Small** | Thin | No / negligible | Most common hits |
| **Medium** | Thicker | Light shake | Heavier hits |
| **Wake** | **Keep current Wake slash** | **Heavier** shake | **Ashbrand Wake only** |

**Wake tier is exclusive:** other cards **must not** use the Wake slash / Wake tier. Do not replace the Wake legendary beat — only layer heavier shake + existing Wake VFX.

---

## NO STROKE (pip on owner)

No You↔foe stroke. Float / pip on the **owner** as appropriate:

| Skills | Note |
|--------|------|
| **Iron Mantle**, **Vow Plate** | Brace on You |
| **Ember Draw** (Brace branch) | Brace on You when Brace grants; still Small stroke on the **Deal 4** hit — Brace grant itself is NO STROKE pip |
| **Hide**, **Rust Guard**, **Cinder Hide** | Brace on enemy |
| Soften / Brand Mark Soften | **No extra slash** beyond the hit stroke; Soften **pip on foe** |

Clarifying Ember Draw: damaging resolve uses **Small** stroke for Deal 4; Brace 2 grant is pip-only (no second stroke).
